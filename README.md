# IDP Drone Simulator v5.4 — CONTROL FIX

v5.3 야외 비행장 화면을 유지하면서 조종 체계를 바로잡은 버전입니다.

## 핵심 수정
- W = 전진
- S = 후진
- A = 좌측 이동
- D = 우측 이동
- ↑ = 상승(고도만 증가)
- ↓ = 하강(고도만 감소)
- ← / → = 기체 회전
- SPACE = 이륙 / 착륙
- R = 초기화

## 전진/후진 체감 개선
W/S를 누르면 드론이 화면 위아래로 크게 움직이는 대신,
야외 배경·훈련장·원근 레이어가 확대/축소 및 이동하여
실제로 앞으로 가거나 뒤로 물러나는 느낌이 나도록 수정했습니다.

기존 유지:
ENTER IDP SYSTEM, 10 LEVEL PROGRAM, LEVEL 1~10, 잠금해제,
LEVEL COMPLETE, LEVEL 2 호버링, RPM/모터음, 야외 훈련장.
