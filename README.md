# IDP Drone Simulator v5.5 — W/S 전후진 확실 분리

v5.4에서 W/S가 화면상 고도 변화처럼 느껴지는 문제를 수정했습니다.

## 조종
- W = 전진
- S = 후진
- A / D = 좌우 이동
- ↑ = 상승 (고도만)
- ↓ = 하강 (고도만)
- ← / → = 회전
- SPACE = 이륙 / 착륙
- R = 초기화

## 핵심 수정
드론의 화면상 위/아래 위치는 이제 ALT(고도)만으로 결정됩니다.
W/S는 드론의 고도를 절대 바꾸지 않습니다.

W를 누르면:
- 배경이 확대
- 훈련장 오브젝트가 가까워짐
- H 착륙장도 커짐
- DIST 값이 증가

S를 누르면:
- 배경이 축소
- 훈련장 오브젝트가 멀어짐
- H 착륙장도 작아짐
- DIST 값이 감소

즉, 전진/후진을 '원근감'으로 느끼도록 분리했습니다.
