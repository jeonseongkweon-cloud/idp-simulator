# IDP Drone Simulator v5.0 — FLIGHT VISUAL UPGRADE

기존 v4.1의 10 LEVEL 카드/잠금해제 구조를 유지하면서 실제 비행 화면의 체감 품질을 크게 높인 버전입니다.

## v5.0 핵심 업그레이드
- 드론 외형을 더 입체적인 쿼드콥터 느낌으로 개선
- 프로펠러 블러/고속 회전 효과
- 상승 시 미세 진동
- 전진/후진/좌우 이동 시 실제 기체처럼 피치/롤 기울기 강화
- 고도에 따라 그림자 크기/투명도/블러 변화
- 고속 이동 시 배경 그리드 러시와 스피드라인 효과
- MOTOR RPM HUD 추가
- Web Audio 기반 모터음
- 이륙 시 RPM 상승 효과
- 착륙 시 RPM 감소 효과
- 기존 LEVEL 1~10 / 점수 / 잠금해제 / 미션 기능 유지
