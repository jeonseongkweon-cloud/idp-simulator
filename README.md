# IDP Drone Simulator v5.2 — OUTDOOR PATCH

이 버전은 v5.0의 성공한 전체 구조를 그대로 유지한 상태에서 비행 배경만 업그레이드한 수정본입니다.

유지되는 것:
- 기존 웅장한 INTRO / ENTER IDP SYSTEM
- 기존 메인 인터페이스
- LEVEL 1~10 카드
- 레벨 잠금/자동 해제
- LEVEL 1 COMPLETE 결과창
- LEVEL 2 HOVERING 및 LEVEL 3~10 미션
- v5.0 드론/프로펠러/RPM/모터음

추가된 것:
- 실제 야외 드론 교육장 느낌의 하늘, 산, 언덕, 잔디
- 훈련 활주로
- IDP TRAINING CENTER 건물
- 풍향주머니
- 안전 콘 / 펜스 / 훈련 게이트
- 노란 H 착륙장
- 드론 좌우 이동에 따른 산/언덕/활주로 패럴랙스
- 고도에 따른 배경 깊이 변화
- 빠른 이동 시 훈련장 속도감
- LEVEL 1과 LEVEL 2에 야외 환경 적용
