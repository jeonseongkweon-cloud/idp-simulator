# IDP Drone Simulator v4.0 — 10 LEVEL PROGRAM

GitHub Pages 전체 덮어쓰기용 버전입니다.

## 핵심 구조
LEVEL 1~10 카드를 처음부터 모두 보여줍니다.
현재 도전 가능한 레벨까지만 클릭할 수 있고, 이전 레벨을 완료해야 다음 단계가 자동으로 열립니다.
진행상태는 브라우저 localStorage에 저장됩니다.

1. 기초 비행
2. 호버링 시험
3. 장애물 링 통과
4. 실종자 수색
5. 산불 좌표 보고
6. 야간 비행
7. 재난지역 정찰
8. 안전 순찰 임무
9. 종합 구조·순찰
10. IDP MASTER CHALLENGE

## 업로드
ZIP 압축 해제 후 안의 파일/폴더 전체를 `jeonseongkweon-cloud/idp-simulator` 저장소 root에 업로드해 기존 파일을 교체하세요.
업로드 후 Ctrl+F5로 강력 새로고침하세요.

## 테스트
메인 LEVEL MAP에서 LEVEL 1부터 시작합니다.
각 레벨 완료 결과창이 뜨면 다음 레벨이 자동으로 OPEN 됩니다.
'진행 초기화' 버튼을 누르면 LEVEL 1부터 다시 테스트할 수 있습니다.
