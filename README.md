# IDP Drone Simulator v5.7 — CLEAN UI + LONG RANGE

이번 버전은 사용자 화면 피드백을 반영한 정리 버전입니다.

## 첫 화면
- 원형 국제드론순찰대 엠블럼만 보이도록 검정 사각 테두리/모서리 제거
- 메인 배경 자체의 로고/문구와 겹치던 중복 제목/설명 제거
- 하단에 버튼 3개 + 진행 단계만 깔끔하게 배치

## 비행 배경
- 기존 배경 이미지에서 대시보드, 배경 드론, H, 우측 패널을 제거한 깨끗한 야외훈련장 배경 사용
- 인터페이스에 추가했던 중복 꼬깔과 TRAINING GATE 제거
- H 착륙장은 실제 조종용 1개만 표시

## 전후진
- W = 전진 / S = 후진
- 기존보다 전후 이동 범위를 크게 확대
- 약 1~2초 후 멈추던 제한을 크게 완화
- DIST 범위 확대
- 배경/착륙장이 장거리 이동에 맞춰 확대·축소
- ↑/↓는 오직 고도만 변경

기존 10 LEVEL / 잠금해제 / 결과 / RPM / 모터음은 유지합니다.
