# IDP Drone Simulator v5.6 — CONTROL + HERO FIX

## 1. 조종 완전 분리
- W = 전진(앞으로)
- S = 후진(뒤로)
- A/D = 좌우 이동
- ↑ = 상승
- ↓ = 하강
- ←/→ = 회전
- SPACE = 이륙/착륙
- R = 초기화

W/S는 이제 전용 `depthPos` 변수만 바꿉니다.
드론의 화면상 높이는 오직 ALT(↑/↓)로만 결정됩니다.

W를 누르면:
- DIST 증가
- 야외훈련장 배경이 크게 확대
- 훈련 게이트/콘/H 착륙장이 가까워짐

S를 누르면:
- DIST 감소
- 배경/훈련장 오브젝트가 멀어짐

## 2. 첫 화면 겹침 수정
배경 이미지 자체에 국제드론순찰대 로고와 INTERNATIONAL DRONE PATROL 글자가 있기 때문에,
앞에 떠 있던 중복 로고와 거대한 중복 영문 제목을 제거했습니다.
하단에 작은 유리 패널 형식으로:
- IDP DRONE TRAINING SYSTEM
- 국제드론순찰대 드론 시뮬레이터
- LEVEL 1~10 안내
- 시작 버튼
만 깔끔하게 표시합니다.

기존 10 LEVEL / 잠금 / 결과 / 야외 비행장 / RPM / 모터음은 유지합니다.
