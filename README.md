# IDP Drone Simulator v2.0

GitHub Pages 저장소 `jeonseongkweon-cloud/idp-simulator`에 덮어쓰기 업로드하는 전체 버전입니다.

## v2.0 업그레이드
- 더 사실적인 쿼드콥터 CSS 그래픽
- 프로펠러 회전, LED, 카메라 짐벌, 고도별 그림자
- 전진/좌우 이동 시 기체 기울기(피치/롤) 효과
- 고도, 속도, 방향각, 배터리 HUD
- LEVEL 1 점수화
- 정밀착륙 점수
- 시간 보너스
- LEVEL 1 완료 화면 + 별 1~3개
- 공개 산불 감시 미션
- 연기 탐지 / 3초 현장 관측 / 안전 복귀
- 산불 미션 결과 화면

## 업로드
ZIP 압축 해제 후 안의 `index.html`, `assets`, `data`, `.nojekyll`, `README.md`를 GitHub 저장소 root에 모두 업로드해 기존 파일을 교체하십시오.

GitHub 웹 업로드에서 같은 경로 파일이 교체되지 않는 경우에는 기존 해당 파일을 삭제한 후 새 파일을 업로드하거나 GitHub Desktop을 사용하면 가장 편합니다.

## 조종
W/S 전후, A/D 좌우, ↑/↓ 상승·하강, ←/→ 회전, SPACE 이륙/착륙, R 초기화, P 일시정지
